# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability within this project, we encourage you to email us at [security@forfreedom95.com](mailto:security@forfreedom95.com). Please include a detailed description of the vulnerability, the steps to reproduce it, and any other relevant information. 

## Disclosure Guidelines
- **Do not disclose the vulnerability publicly until it has been addressed.**
- We will respond within 72 hours of your report with our assessment and a timeline for remediation.
- If the vulnerability is confirmed, we will credit you in our release notes unless you prefer to remain anonymous.
- This security policy may be updated over time, and we encourage you to check back regularly for updates.

## Security Best Practices
We recommend that you take the following precautions when analyzing the software:
- Use the latest stable version.
- Regularly check the project's repository for updates and security patches.
- Follow secure coding practices to minimize the risk of vulnerabilities.
